# 선교 이후의 연결과 책임

몽골선교 스터디를 위한 10장짜리 HTML 발표 슬라이드입니다.

## 보기

https://noy3928.github.io/mongolia-mission-slides/

이전·다음 버튼이나 키보드 방향키로 이동할 수 있습니다. 아래 진행 표시를 누르면 해당 슬라이드로 이동합니다.

## 디자인

사용자가 제공한 참고 이미지의 낡은 종이 질감과 전통 문양, 먹색 선화에서 디자인 방향을 가져왔습니다. 표지와 마무리에는 게르와 말, 산맥의 일러스트를 사용하며, 본문은 장식 테두리와 여백을 중심으로 구성했습니다. 배경은 참고 이미지를 바탕으로 OpenAI image_gen으로 생성했습니다. 실제 방문 사진이 아닙니다.

## 수정과 배포

`index.html`을 수정하고 `main` 브랜치에 푸시하면 GitHub Pages가 자동으로 배포합니다. 배경과 제목 글꼴은 HTML에 포함되어 파일 하나로 실행할 수 있습니다.

## 글꼴과 본문

제목 글꼴은 Noto Serif KR입니다. Google Fonts에서 필요한 문자만 포함하는 파일을 받아 사용했으며, SIL Open Font License 1.1이 적용됩니다. 라이선스 전문은 `OFL-NotoSerifKR.txt`에 있습니다.

성경 관련 문구는 빌립보서 1:3–5의 내용 요약입니다.
