# 선교 이후의 연결과 책임

몽골선교 스터디를 위한 10장짜리 HTML 발표 슬라이드입니다.

## 보기

https://noy3928.github.io/mongolia-mission-slides/

이전·다음 버튼이나 키보드 방향키로 이동할 수 있습니다. 아래 진행 표시를 누르면 해당 슬라이드로 이동합니다.

## 수정과 배포

`index.html`을 수정하고 `main` 브랜치에 푸시하면 GitHub Pages가 자동으로 배포합니다. 사진은 HTML에 포함되어 있어 파일 하나로도 실행할 수 있습니다.
